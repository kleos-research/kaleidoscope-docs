{(() => {
  // public-docs-release.json is the author of the release version, and this
  // page renders it. src/data/status.json is served byte for byte at
  // /status.json and cannot import, so it carries a literal copy. A bump that
  // changes one file and forgets the other stops the build here. Renders
  // nothing.
  if (status.packages.version !== release.release_version) {
    throw new Error(
      'the release version disagrees with itself: public-docs-release.json says ' +
        release.release_version +
        ' and src/data/status.json says ' +
        status.packages.version +
        '. public-docs-release.json is the author; change status.json to match it.',
    );
  }
  return '';
})()}

<p class="k-meta">As of {status['as of']}</p>

Kaleidoscope installs from npm and runs on your machine. It needs a key.
Nothing is signed for release, and there is no account to sign in to.

## Install

```bash
npm install -g @kleos-research/kaleidoscope
```

macOS and Linux, on Apple Silicon and x86_64. Windows is not supported yet.

Email [contact@kleosresearch.xyz](mailto:contact@kleosresearch.xyz) for a key,
then follow [Getting started](/docs/getting-started/).

## What is current

| | |
|---|---|
| Package | {release.release_version} on npm |
| Documentation | updated {status['as of']} |
| Signed builds | none, so what you install is unsigned software |
| Accounts | none, and none to create |
| Python package | none — `kscope-memory` on PyPI is a 0.0.0 placeholder with no working code, and `kaleidoscope-memory` was never registered |

Nothing here is hosted, so there is no uptime to report. If a hosted service
ships, its status appears on this page.
