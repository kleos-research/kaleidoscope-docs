## Install it

```bash
npm install -g @kleos-research/kaleidoscope
```

Then activate it with your key and give a project a memory:

```bash
export KALEIDOSCOPE_API_KEY=<your key>
kscope activate
cd ~/your-project && kscope init
```

You need a key to run it. Email [contact@kleosresearch.xyz](mailto:contact@kleosresearch.xyz)
and we will send you one. Full walkthrough in
[getting started](/docs/getting-started/).

## What you get

**It stays on your machine.** Your memory is a folder inside your project. The
part that stores and searches it runs on your laptop and needs no network, so
what you write down is not something we can read.

**One memory, every tool.** Claude Code, Codex, Cursor and OpenCode all read the
same vault. Something your agent learned in one of them is there in the next.

**Your agent drives it.** `kscope init` wires up whichever tool you use, and
from then on you just talk normally — ask it what you decided last week, or tell
it to remember something. The two commands it uses are the only two it sees.
