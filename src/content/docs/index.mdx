## Install it

```bash
npm install -g @kleos-research/kaleidoscope
export KALEIDOSCOPE_API_KEY=<your key>
kscope activate
cd ~/your-project && kscope init
```

Restart your editor, then ask it what you decided last week.

No key yet? Email
[contact@kleosresearch.xyz](mailto:contact@kleosresearch.xyz).
[Getting started](/docs/getting-started/) walks the same four steps slowly.

## What you get

**It stays on your machine.** Your memory is a folder inside your project,
served by a process on your laptop. Nothing is uploaded.

**One memory, every tool.** Claude Code, Codex, Cursor and OpenCode read the
same vault. What your agent learned in one is there in the next.

**Your agent drives it.** `kscope init` wires whichever editors you already
have. After that you talk normally, and it decides when to read and when to
write.
