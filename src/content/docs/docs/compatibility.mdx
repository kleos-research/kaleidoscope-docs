your machine. You need a key to run it, and nothing is signed for release.

## Compiler checks

A compiler check is not a build: nothing was assembled, linked or run. Three of
the platforms below were built and published afterwards, and appear in the table
above.

## Windows

Windows is not supported yet.

| | |
|---|---|
| Package | not published |
| Creating a vault | refused on purpose |
| What is missing | file locking, link handling, and flushing writes to the disk |

Until that filesystem work lands, `kscope` stops rather than writing memory it
cannot stand behind.

The same matrix, machine-readable:
[platform-support.json](/platform-support.json).
