Kaleidoscope is local memory for agents. Memories live in a vault on your
machine, and every editor you connect reads that vault through one command,
`kscope`.

```bash
npm install -g @kleos-research/kaleidoscope
```

Running it needs a key — email
[contact@kleosresearch.xyz](mailto:contact@kleosresearch.xyz). There is no
account to create and no sign-in.

`kscope` is the one executable published. Verbs written about elsewhere —
`connect`, `disconnect`, `config`, `doctor`, `teardown`, `profile use`,
`instructions install`, and the account surface — belong to a second program
that ships on no channel; [the CLI reference](/docs/cli/) gives what to run in
their place.
