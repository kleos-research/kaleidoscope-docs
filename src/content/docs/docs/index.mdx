Kaleidoscope is local memory for agents. Your memory lives in a vault on your
machine, and every editor or agent you connect shares one profile through a
command-line tool and a long-lived process that offers exactly two tools.

Install it with `npm install -g @kleos-research/kaleidoscope`. You need a key to
run it — email [contact@kleosresearch.xyz](mailto:contact@kleosresearch.xyz) and
we will send you one. There is no account to create and no sign-in.
[What works today](/status/) is the plain answer to what is covered.

- [Account commands](/docs/cli/account/) — the account surface, none of which
  ships, and `activate`, which is what there is instead.

Several verbs written down elsewhere are not in the command you can install.
`connect`, `disconnect`, `config`, `doctor`, `teardown`, `profile use`,
`instructions install` and every account command belong to a separate
`kaleidoscope` executable that is published on no channel, so they are commands
you cannot obtain rather than commands you can run. What ships in their place is
`kscope init`, which does the wiring and installs the instruction file and the
skill itself, and `kscope call doctor`, which is the diagnostic.
