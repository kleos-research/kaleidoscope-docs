---
title: LangGraph
description: Put Kaleidoscope's two tools in a LangGraph tool node, without turning it into a graph store or a checkpointer.
---

Install and activate first — [Getting started](/docs/getting-started/) covers both. Without a
key the wiring below succeeds and the server refuses with `E_NO_KEY` the moment your editor
starts it.

The same one-session MCP adapter as LangChain, placed in your graph's tool node.

## Get the descriptor

```bash
cd ~/your-project
kscope init --no-wire
kscope profile import default ~/your-project/.kaleidoscope
kscope profile launch default
```

Copy `command` and `args` into the adapter's server definition.
[Any other MCP client](/docs/integrations/generic-mcp/) explains each field.

## Wire it in

Open the adapter before you execute the graph, pass `search` and `remember` into
the tool node, and close it once execution finishes. Node calls reuse the same
session.

Do not use Kaleidoscope as a checkpointer or a `BaseStore`.

## Check it

The tool node should hold `search` and `remember`, and your checkpointer should
be something else.

## Remove it

Close the adapter after the graph finishes and delete the server definition from
your own configuration.
