title: CrewAI
description: Run Kaleidoscope as one stdio MCP adapter context for a whole CrewAI crew run, exposing two tools.
---

Install and activate first — [Getting started](/docs/getting-started/) covers both. Without a
key the wiring below succeeds and the server refuses with `E_NO_KEY` the moment your editor
starts it.

One adapter context for the whole crew run, not one per task.

## Get the descriptor

```bash
cd ~/your-project
kscope init --no-wire
kscope profile import default ~/your-project/.kaleidoscope
kscope profile launch default
```

Copy `command` and `args` into the adapter's server definition.
[Any other MCP client](/docs/integrations/generic-mcp/) explains each field.

## Wire it in

Build the adapter from the descriptor, enter the context once, select `search`
and `remember`, run the crew, then close the context. Do not recreate the server
for each task.

## Check it

Your agents should hold `search` and `remember`, from one adapter context shared
across the crew.

## Remove it

Close the adapter context at the end of the run and delete the server definition
from your own configuration.
