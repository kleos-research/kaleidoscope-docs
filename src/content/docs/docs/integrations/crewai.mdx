---
title: CrewAI
description: Run Kaleidoscope as one persistent MCP adapter context for a CrewAI crew, exposing only two tools.
---

CrewAI uses one stdio MCP adapter context for the whole crew run, and exposes
only the Kaleidoscope tools you choose to give the model.

## Connect it

```bash
kaleidoscope config --profile default --json
```

Build the adapter from that descriptor, enter it once, select `search` and
`remember`, run the crew, then close the context. Do not recreate the server for
each task.

## What it writes

Nothing on your disk. CrewAI owns your provider configuration and your crew
state; Kaleidoscope owns only the local memory, and never receives a
model-provider credential or an account token.

## Disconnect

Close the adapter context at the end of the crew run and remove the descriptor
from your own configuration.
