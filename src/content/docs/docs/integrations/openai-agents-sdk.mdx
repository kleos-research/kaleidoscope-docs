---
title: OpenAI Agents SDK
description: Attach Kaleidoscope to an OpenAI Agents SDK run as one long-lived stdio MCP server with two tools.
---

Install and activate first — [Getting started](/docs/getting-started/) covers both. Without a
key the wiring below succeeds and the server refuses with `E_NO_KEY` the moment your editor
starts it.

Use the stdio MCP server lifecycle the SDK already gives you. One server, alive
for the run.

## Get the descriptor

```bash
cd ~/your-project
kscope init --no-wire
kscope profile import default ~/your-project/.kaleidoscope
kscope profile launch default
```

Copy `command` and `args` into the server definition.
[Any other MCP client](/docs/integrations/generic-mcp/) explains each field.

## Wire it in

Create the MCP server as a managed resource around the run and close it at the
end. Do not open a fresh engine process per tool call.

Filter the model-facing tools to `search` and `remember`.

## Check it

The agent's tool list should hold `search` and `remember`, and nothing else from
this server.

## Remove it

Delete the server definition from your own configuration.
