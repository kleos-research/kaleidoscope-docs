title: Claude Code
description: What kscope init writes for Claude Code — the MCP entry in ~/.claude.json, the CLAUDE.md block, and the project skill.
---

Claude Code is wired by the same command as everything else. `kscope init`, run
in a project, sees Claude Code on this machine and does three things for it:
registers the memory server, writes the instruction block, and installs the
skill. Everything it writes is marked as its own, so you can find it again.

## Wire it

```bash
cd ~/your-project
kscope init
```

Claude Code counts as present when `~/.claude` or `~/.claude.json` exists. Both
are written by Claude Code itself, and neither is a path this command would
create on its way to looking, so its absence means Claude Code is left alone
rather than given a configuration file it never asked for.

## What it writes

The MCP entry goes in `~/.claude.json`, under `mcpServers` as `kaleidoscope`:
`"type": "stdio"`, this executable's absolute path, and the arguments
`mcp --profile default`. That file is Claude Code's own live configuration and
is usually large; only the entry Kaleidoscope owns is written, the rest comes
back as it was, and a receipt is left beside it in
`~/.claude.json.kaleidoscope-owner.json`.

The instruction block goes in `CLAUDE.md` in the project, between
`kaleidoscope-manager` marker comments, with the rest of the file untouched.

The skill goes in `.claude/skills/use-kaleidoscope/SKILL.md` in the project.
That is where Claude Code looks for a skill; it does not read `.agents/skills/`,
which is why this path differs from the one Codex and OpenCode get.

The server those entries start publishes only `search` and `remember`. Nothing
written carries your vault location, a provider key, or an account credential.

Restart Claude Code afterwards. Until you do, it is still running with the
configuration it started with.

## Removing it

There is no `disconnect` on the command you have: the verb exists only in
`kaleidoscope`, the manager executable, which is built from source and published
on no channel. So you take the wiring out by hand — the `kaleidoscope` entry in
`~/.claude.json`, the marked block in `CLAUDE.md`, and
`.claude/skills/use-kaleidoscope/` — along with the receipt beside each one,
which is the record of what was put there.
[Connect an editor or agent](/docs/cli/connect/) has the whole list in one
place.
