---
title: LangChain
description: Load Kaleidoscope's two tools into one LangChain MCP adapter session, without adding a second memory store.
---

Install and activate first — [Getting started](/docs/getting-started/) covers both. Without a
key the wiring below succeeds and the server refuses with `E_NO_KEY` the moment your editor
starts it.

Use the official LangChain MCP adapter, one session for the whole run.

## Get the descriptor

```bash
cd ~/your-project
kscope init --no-wire
kscope profile import default ~/your-project/.kaleidoscope
kscope profile launch default
```

Copy `command` and `args` into the adapter's server definition.
[Any other MCP client](/docs/integrations/generic-mcp/) explains each field.

## Wire it in

Open the stdio adapter before the agent run, load `search` and `remember`, and
close it when the run is over.

Do not wrap Kaleidoscope as a `BaseStore`, and do not attach a second LangChain
memory alongside it.

## Check it

The adapter should have loaded `search` and `remember`, and your agent should
have no other memory component attached.

## Remove it

Close the adapter and delete the server definition from your application
configuration.
