---
title: Claude Agent SDK
description: Give a Claude Agent SDK run one Kaleidoscope stdio MCP client and a two-name tool allowlist.
---

Install and activate first — [Getting started](/docs/getting-started/) covers both. Without a
key the wiring below succeeds and the server refuses with `E_NO_KEY` the moment your editor
starts it.

One client, one process, for the whole run.

## Get the descriptor

```bash
cd ~/your-project
kscope init --no-wire
kscope profile import default ~/your-project/.kaleidoscope
kscope profile launch default
```

Copy `command` and `args` into the SDK's stdio MCP configuration under the
server name `kaleidoscope`.
[Any other MCP client](/docs/integrations/generic-mcp/) explains each field.

## Wire it in

Open the client once around the run and close it at the end. Do not start a
fresh engine process per tool call.

Write the tool allowlist out in full:

```text
mcp__kaleidoscope__search
mcp__kaleidoscope__remember
```

## Check it

The run's tool list should hold those two names and no other
`mcp__kaleidoscope__` entry.

## Remove it

Delete the server from your SDK configuration.
