```bash
npm install -g @kleos-research/kaleidoscope
```

That is the whole install. You need a key to run it — email
[contact@kleosresearch.xyz](mailto:contact@kleosresearch.xyz) and we will send
you one.

## What your machine needs

| | |
|---|---|
| operating system | macOS or Linux |
| architecture | Apple Silicon or x86_64 |
| Node.js | 18 or newer |

Windows is not supported yet. The package will install there, but creating a
vault is refused on purpose until the filesystem work is done.

There is no Python package. `kaleidoscope-memory` on PyPI was planned and never
registered; if you find that name, it is not us.

## What it puts on your disk

Two things. The first is the `kscope` command and a small amount of JavaScript
that picks the right binary for your machine. The second is a package built for
your platform, which carries the part that stores and searches your memory.

There is no install hook, no download at install time, no compiler step and no
source-build fallback. Installing puts files on your disk and does nothing else.

The part that stores and searches your memory is proprietary object code, and
its source is not in the package. A native binary is still inspectable —
shipping object code is not a claim that it cannot be read. Everything around
it is Apache-2.0: the command-line tool, both SDKs, every integration and the
agent skill.

## Signing

Nothing is signed for release. There is no Apple signing and no notarisation,
and the native code is ad-hoc signed only. That is worth knowing before you
install, and it is on the list to fix.
