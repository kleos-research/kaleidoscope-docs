Kaleidoscope has not been released, so there are no release notes yet. When it
is released, every version will be listed here, newest first.

Each entry will say which platforms that version runs on, which editor and agent
versions it was checked against, what changed, what broke or was removed, whether
anything you already have needs to be moved or reconfigured, and any security
fixes it carries.

Until then, [Status](/status/) is the current picture: what is available, what
is not, and what has actually been run.
