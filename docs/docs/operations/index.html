Operations

Your memory is one directory: .kaleidoscope, inside your project. Everything on this page works on that directory, and none of it needs an account.

To find out which vault a project resolves to, run kscope where — see Diagnostics.

Back it up

Section titled “Back it up”

Close the editors and agents using the vault, then copy the directory whole.

A partial copy is not a vault.

Move it to another machine

Section titled “Move it to another machine”

Put the directory where you want it, then name it and check it.

profile import reads the identity out of the vault and writes a profile called restored. Start an agent against it with --profile restored. vault-verify prints "status":"complete" when the copy is whole.

Do not run kscope init on a vault you moved. It leaves the vault alone, but it rewrites that project’s editor wiring.

Delete a vault

Section titled “Delete a vault”

Two commands. Preview first.

You get an inventory — entries, bytes, what is canonical and what is rebuildable — and a confirmation_token. Pass that token back:

The token belongs to the root you previewed. Point it at another vault and you get confirmation token does not match this vault root and path, and nothing is deleted.

Deleting the vault deletes the memories in it. CLAUDE.md, AGENTS.md, the Cursor rule and the skill directories stay where they are; remove those separately.

Remove Kaleidoscope

Section titled “Remove Kaleidoscope”

Four separate things. Removing any of them leaves your memory where it is.

WhatHow
the packagenpm uninstall -g @kleos-research/kaleidoscope
an editor’s connectiondelete the Kaleidoscope entry from that editor’s configuration file
the agent instructionsdelete the marked block from CLAUDE.md or AGENTS.md, then .cursor/rules/kaleidoscope.mdc and the use-kaleidoscope skill directories
the vaultpreview and delete it, above

Every block kscope init writes sits between kaleidoscope-manager markers, with a receipt file beside it. Removal is by hand: kscope has no disconnect verb.

Encrypted vaults on macOS

Section titled “Encrypted vaults on macOS”

A vault can live inside an encrypted disk image. This is a frozen macOS preview.

macOS generates the password, keeps it in your login Keychain, and shows you a recovery key once. Write the recovery key down. It is the only copy.

TaskCommand
create onekscope vault-create <REPOSITORY> <RFC3339_CREATED_AT>
open, closekscope vault-open, kscope vault-close
recover with the keykscope vault-recover
move the device packagekscope vault-export-device, kscope vault-import-device
inventory, deletekscope vault-encrypted-preview, kscope vault-encrypted-delete

Each takes a repository path. The help text has the arguments.
