Local memory for agents · one vault · every tool

Your agent forgets. This is where it remembers.

Every new session, your coding agent starts from nothing. It re-asks questions you already answered, re-reads code it already understood, and repeats mistakes you already paid for. Kaleidoscope gives it a memory that stays on your machine and follows you between tools.

Your agent gets two things it can do: look something up, and write something down. Everything it stores lives in a folder in your project. No server, no account, and nothing leaves your disk.

What you get

Section titled “What you get”

It stays on your machine. Your memory is a folder inside your project. The part that stores and searches it runs on your laptop and needs no network, so what you write down is not something we can read.

One memory, every tool. Claude Code, Codex, Cursor and OpenCode all read the same vault. Something your agent learned in one of them is there in the next.

Your agent drives it. kscope init wires up whichever tool you use, and from then on you just talk normally — ask it what you decided last week, or tell it to remember something. The two commands it uses are the only two it sees.
